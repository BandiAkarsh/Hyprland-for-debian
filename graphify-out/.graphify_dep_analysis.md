## 10. Conclusion

Building Hyprland 0.55.0 on Debian 12 (Bookworm) out of the box is impossible due to:

1. **Compiler**: Requires GCC 14+ (for C++26 mode and `<print>`); Debian 12 has GCC 12.2.
2. **CMake**: Requires 3.30+; Debian 12 has 3.25.1 (but backport exists).
3. **Wayland stack**: Requires wayland-server >= 1.22.91 and wayland-protocols >= 1.47; Debian 12 has 1.21.0 and 1.31 respectively.
4. **libinput**: Requires >= 1.28; Debian 12 has 1.22.1.
5. **Hyprland ecosystem**: 7+ custom libraries (aquamarine, hyprlang, hyprcursor, hyprutils, hyprgraphics, hyprwayland-scanner, hyprwire) not packaged in Debian at all.
6. **Lua 5.5**: Hyprland requires Lua 5.5 (`lua>=5.5 lua<5.6`); Debian 12 has Lua 5.4.

The **minimum viable upgrade path** for a Debian 12 user would require:
- Installing GCC 14/15 from backports or building from source
- Installing CMake 3.30+ from backports
- Building wayland 1.22.91+, wayland-protocols 1.47+, and libinput 1.28+ from source
- Building and installing all 7+ Hyprland ecosystem libraries from source
- Building Lua 5.5 from source
